CONTRATO DE RECUPERAÇÃO
Cada boot/load e cada instalação tem um único orçamento de remontagem a1MHz.
O caminho normal permanece4MHz; nenhuma preferência de frequência é persistida.
Não se usa SPI.end. OTA fecha os leitores antes de remontar sob updateSpi,
mesmo mutex da tela, CS41/45 altos e pausa150ms. Nenhum hash/crc parcial é reutilizado.
O leitor rejeita também retorno completo acompanhado de errno e open truthy com
errno (o core pode ter fstat falho e size em cache). Lookup ausente e erro de lookup
são distintos. EIO não autoriza apagar staging ou pacote final.

Downloads .part têm tag SHA64 exata e tamanho limitado pelo manifesto. Tag ilegível
preserva o par. Tag completa incompatível não é retomada. Pacote completo dispensa
novo HTTP, mas nunca dispensa SHA integral, tamanho, cabeçalho/catálogo/CRC.
Em mismatch confirmado, apenas o staging afetado é invalidado; o outro permanece.
Espaço é calculado pelos bytes ainda necessários, com reserva1MiB. Espaço desconhecido
não é tratado como espaço confirmado. OTA abortada/ativação falha conserva staging.
A cópia para flash reinicia SHA sobre os bytes efetivamente enviados a esp_ota_write;
sem SHA correto e esp_ota_end bem-sucedido não se escolhe o novo boot.

PROMOÇÃO E INTERRUPÇÃO
1. .part verificado; final antigo permanece. Se final e .bak já existem, parar.
2. Renomear final -> .bak sem substituir backup. Queda aqui: backup continua legível
   pelo novo boot, staging continua disponível; nenhum arquivo é apagado.
3. Renomear .part -> final. Queda aqui: boot valida final inteiro e pode tentar backup.
4. Revalidar final. Falha: tentar final -> .part, depois .bak -> final quando este
   backup foi criado pela tentativa. Rollback que falha não apaga os nomes restantes.
5. Só selecionar boot após arte e firmware validados. Limpar temporários depois.
Backup e outros pacotes não são apagados no boot. O boot seleciona somente o nome
do CRC compilado, artes.pak ou backup desse CRC; não escolhe outro catálogo antigo.
Interrupções simuladas não provam atomicidade FAT nem imunidade a falha elétrica.
